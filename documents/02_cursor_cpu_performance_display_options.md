타이틀바에 CPU를 그리도록 하고, progress bar / line graph 중 선택할 수 있게 구현합니다. 최소화 시에는 타이틀바가 보이지 않으므로, 일반 상태에서는 NC 영역에 그리고 최소화 시에는 모드별로 taskbar·제목 텍스트로 표시합니다.


제목 표시줄에 CPU를 **진행 표시줄** 또는 **꺾은선 그래프**로 보이도록 선택할 수 있게 했습니다.

## 변경 사항

**설정 UI** — `제목 표시줄 표시 방식` 그룹에서 선택:
- **진행 표시줄** — 제목 표시줄 오른쪽(창 버튼 왼쪽)에 채워지는 막대
- **꺾은선 그래프** — 최근 CPU 샘플을 이어 그린 선

**일반/최대화 상태** — 비클라이언트 영역(`WM_NCPAINT`)에 직접 그립니다.

**최소화 상태** — 창 제목 표시줄은 그려지지 않으므로:
- 진행 표시줄: `CPU 45%` + 작업 표시줄 progress(기존과 동일)
- 꺾은선 그래프: `CPU ▁▂▅▇█ ... 45%` 형태의 스파크라인 문자열

설정은 `settings.json`의 `TitleBarDisplayMode`에 저장됩니다.

- `TitleBarCpuRenderer.cs` — 그리기·히스토리·최소화 시 제목 포맷
- `NativeMethods.cs` — 제목 표시줄 갱신용 Win32 API

## 원인

Windows에서 창을 일반적으로 최소화하면 HWND가 숨겨져 **제목 표시줄에 직접 그릴 수 없습니다.** 그래서 이전에는 작업 표시줄 버튼 제목(`CPU 45%`)만 바뀌었습니다.

## 해결: 컴팩트 제목 표시줄 모드

꺾은선 그래프를 선택한 뒤 최소화하면:

1. 일반 최소화 대신 **제목 표시줄 높이만 남기고** 본문은 숨깁니다.
2. 창은 작업 표시줄에 그대로 보이며, **제목 표시줄에 꺾은선 그래프 + CPU %**가 갱신됩니다.
3. **복원**: 제목 표시줄 더블 클릭, 또는 복원(□) 버튼 → 이전 크기·설정 UI로 돌아갑니다.

진행 표시줄 모드는 기존처럼 일반 최소화 + 작업 표시줄 progress를 사용합니다.

## 사용 방법

1. **꺾은선 그래프** 선택  
2. 최소화 버튼 클릭 → 화면에 얇은 제목 표시줄만 남고 그래프 표시  
3. 제목 표시줄 더블 클릭 또는 복원으로 전체 창 복구  

한번 실행해 보시고, 최소화 후 제목 표시줄에 선 그래프가 보이는지 확인해 주세요.

컴팩트 모드에서 복원 버튼·최소화 버튼·작업 표시줄 복원이 제대로 처리되도록 `WndProc`와 `ExitCompactTitleBarMode`를 수정합니다.


컴팩트(꺾은선 그래프 최소화) 모드에서 복원이 안 되던 문제를 수정했습니다.

## 원인

1. **복원(□) / 작업 표시줄 복원** 시 `WindowState`가 `Minimized`로 남아 창이 다시 보이지 않음  
2. **제목 표시줄 복원 처리** 후에도 `DefWndProc`가 같은 명령을 다시 처리함  
3. 컴팩트 모드는 OS 기준으로는 “일반 창”이라, **최소화 버튼**이 복원이 아니라 다시 최소화로 동작함  

## 수정 내용

- **복원 시** `WindowState = Normal`로 명시한 뒤 저장해 둔 크기·UI 복구  
- **작업 표시줄에서 복원**할 때도 동일하게 전체 창으로 복구  
- 컴팩트 모드에서 **복원(□)·최소화(−)·제목 표시줄 더블 클릭** → 전체 창 복구 (기본 처리 차단)  
- 컴팩트 중 **최소화(−) 버튼** → 다시 누르면 전체 창으로 펼쳐지도록 토글  

## 사용 방법

꺾은선 그래프 → 최소화 → 제목 표시줄만 남은 상태에서:

- **제목 표시줄 더블 클릭**, 또는  
- **최소화(−) 버튼** 다시 클릭, 또는  
- **작업 표시줄 아이콘** 클릭  

으로 전체 창이 복원되어야 합니다. 한번 확인해 보시고, 여전히 안 되면 어떤 버튼(제목 표시줄 / 작업 표시줄)인지 알려 주세요.
